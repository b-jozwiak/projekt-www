## Koncepcja:
### Wykorzystywane dane
Aplikacja będzie korzystać z danych o grach komputerowych pobieranych z API. Dane obejmują m.in. nazwę gry, gatunek, platformę, datę wydania, ocenę, opis oraz grafikę gry.

### Podstawowe funkcje:
- pobieranie i wyświetlanie listy gier z API
- wyszukiwanie oraz filtrowanie gier według kategorii lub platformy
- wyświetlanie szczegółowych informacji o wybranej grze
- możliwość zapisywania wybranych gier do listy ulubionych (localStorage)

### Planowane główne widoki:
- widok listy gier
- widok szczegółów gry
- formularz wyszukiwania / filtrowania gier
- widok ulubionych gier użytkownika
